# Things I See on the Road

## Project Description

This project is part of the Dear Data 100 Creative Coding
assignment.

I am collecting observations of things that I see while
travelling on the road.

Each observation records:

- Date
- Time
- Object
- Category
- Colour

The current dataset contains 25 observations collected
between 20 October and 24 October 2026.

The data is being visualised using Processing.

The project will continue to collect observations until
at least 100 data points have been recorded.
